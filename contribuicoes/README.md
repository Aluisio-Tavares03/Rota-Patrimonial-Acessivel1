## Passo a passo (pelo site do GitHub, sem instalar nada)

1. Entre no GitHub **com a sua conta** e aceite o convite de colaborador do repositório (chega no e-mail). Se não chegou, peça ao Aluisio.
2. Abra o site da v0.1 (link no `README.md`) e faça o que o seu arquivo pede. Tire um print de cada teste.
3. Envie os prints: abra a pasta `evidencias/` → **Add file → Upload files** → arraste os prints com o nome do teste e o seu nome (ex.: `M02-luiz.png`) → **Commit changes**.
4. Abra o **seu** arquivo nesta pasta → ícone do lápis (Edit) → troque cada `[preencher]` pelo que você fez e viu → **Commit changes**. Na mensagem do commit, escreva algo como "Registra os testes M01, M07 e M08 (T09)".
5. O link da sua contribuição é o commit que você acabou de fazer, ou a página `commits?author=SEU_USUARIO` do repositório.

Se o e-mail da sua conta do GitHub não for o mesmo do commit, o commit não aparece ligado ao seu perfil. Editando direto pelo site, isso não acontece.
